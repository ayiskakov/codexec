# Valid Parentheses

A string of brackets is valid when every opening bracket is closed by the same
kind of bracket, in the correct order.

## Input

One line containing only the characters `()[]{}`, length between 1 and 200000.

## Output

`true` if the string is valid, otherwise `false`.

## Examples

| Input | Output |
| --- | --- |
| `()[]{}` | `true` |
| `(]` | `false` |
